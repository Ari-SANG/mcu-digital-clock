# 串口时间同步上位机

该程序使用 C# WinForms，包含独立的“时间同步”和“闹钟设置”界面。
它支持电脑时间自动校准、手动设置时间，以及分别修改单片机中的三组闹钟。

## 使用方法

1. 先给单片机烧录工程生成的最新 `Objects\Uart1_Demo.hex`。
2. 关闭 STC-ISP 或其他正在占用串口的软件。
3. 运行 `bin\SerialTimeSync.exe`。
4. 选择 CH340 对应的 COM 口并单击“连接”。
5. 在“时间同步”页选择自动校准或手动发送。
6. 在“闹钟设置”页填写任意一组闹钟的时、分，再单击对应的写入按钮。

上位机使用 115200、8N1，发送 `01 HH MM SS AA`。固件按实测的 11.0592 MHz
系统时钟计算波特率。时间字段为 BCD；单片机
接受有效数据后回复 `06`。只有收到该 ACK，界面才会显示同步成功。

修改闹钟使用 `02 NN HH MM AA`：`NN` 为二进制编号 `01`、`02` 或 `03`，
`HH` 和 `MM` 为 BCD 编码的时、分。成功写入后单片机回复 `06`，并切换到
对应闹钟的显示界面。三组闹钟上电默认值为 08:00、12:00、16:00。

程序连接时关闭 DTR 和 RTS，并在打开串口后等待 1.5 秒，以兼容可能触发
单片机复位的自动下载电路。串口连接会一直保持到用户单击“断开”或退出程序。

双击 `build.bat` 可以使用 Windows 自带的 .NET Framework 编译器重新生成 EXE。
