# 串口时间同步上位机

该程序使用 C# WinForms，包含独立的“时间同步”“闹钟设置”和“温度显示”界面。
它支持电脑时间自动校准、手动设置时间，以及分别修改单片机中的三组闹钟
和每组闹钟使用的音乐，并可分别启用或关闭三组闹钟。

## 使用方法

1. 先给单片机烧录工程生成的最新 `Objects\Uart1_Demo.hex`。
2. 关闭 STC-ISP 或其他正在占用串口的软件。
3. 运行 `bin\SerialTimeSync.exe`。
4. 选择 CH340 对应的 COM 口并单击“连接”。
5. 在“时间同步”页选择自动校准或手动发送。
6. 在“闹钟设置”页填写任意一组闹钟的时、分并选择音乐，单击“写时间”修改
   该组时间与音乐；勾选或取消“启用”后，单击“写开关”单独修改启用状态。
   勾选框是待发送值，并非单片机当前状态的读回显示。
7. 在“温度显示”页单击“立即读取”，或保持“每秒自动刷新”勾选；自动刷新
   只在该页激活时进行，查询失败会暂停，以免连续发送无效请求。

上位机使用 115200、8N1，发送 `01 HH MM SS AA`。固件按实测的 11.0592 MHz
系统时钟计算波特率。时间字段为 BCD；单片机
接受有效数据后回复 `06`。只有收到该 ACK，界面才会显示同步成功。

修改闹钟使用 `02 NN HH MM AA`：`NN` 为二进制编号 `01`、`02` 或 `03`，
`HH` 和 `MM` 为 BCD 编码的时、分。成功写入后单片机回复 `06`，并切换到
对应闹钟的显示界面。三组闹钟上电默认值为 08:00、12:00、16:00。

新版助手使用扩展帧 `03 NN HH MM MU AA`，其中 `MU` 为二进制音乐编号
`01`、`02` 或 `03`，依次代表《欢乐颂》《天空之城》《曹操》。
固件仍兼容旧的 `02` 帧；旧帧只更新时间，不改变该组已经选择的音乐。

开关使用独立帧 `04 NN EN AA`，`EN=01` 为启用、`EN=00` 为关闭。
它不会改动原有的闹钟时间和音乐，旧 `02`、`03` 帧也不会改动开关状态。
开关状态保存在单片机 EEPROM 中，断电后仍能恢复；关闭正在响铃或贪睡中
的闹钟会立即停止或取消后续响铃。首次升级旧版 EEPROM 数据时，三组闹钟
均视作启用。

读取温度发送 `05 AA`，单片机返回 `05 WW DD AA`。`WW` 为二进制整数温度，
`DD` 为二进制十分位，示例 `05 1A 01 AA` 表示 26.1°C。温度数据来自板载
P1.0/ADC0 热敏电阻，和数码管温度页使用相同换算逻辑；查询不更改设置，也
不会写入 EEPROM。旧版 HEX 不支持此命令，使用前须先烧录最新版。

程序连接时关闭 DTR 和 RTS，并在打开串口后等待 1.5 秒，以兼容可能触发
单片机复位的自动下载电路。串口连接会一直保持到用户单击“断开”或退出程序。

双击 `build.bat` 可以使用 Windows 自带的 .NET Framework 编译器重新生成 EXE。
