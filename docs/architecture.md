# 程序架构与原理

[阅读导航](README.md) · [当前固件入口](../firmware/main.c)

## 沿实际调用顺序阅读

`main.c` 关闭总中断后初始化 Board、Settings、Music、Keys、UART，再开启中断并初始化 App。主循环持续执行 `App_Service()`；有 10 ms 节拍时调用 `App_Tick10ms(Keys_Scan10ms())`；最后执行 `Settings_Service()`。

| 文件 | 职责 | 阅读重点 |
| --- | --- | --- |
| [main.c](../firmware/main.c) | 初始化、协作式调度 | 前台服务与 10 ms 周期任务 |
| [config.h](../firmware/config.h) | 全局配置 | FOSC、学号、闹钟、息屏和按键时序 |
| [app.c](../firmware/Application/app.c) | UI 状态与事件 | CLOCK / STUDENT / ALARM，编辑、唤醒、串口请求 |
| [board.c](../firmware/Drivers/board.c) | GPIO、显示扫描、时钟、ADC、闹钟 | Timer1 ISR、显示缓冲、时间进位、温度近似 |
| [keys.c](../firmware/Drivers/keys.c) | 按键消抖与连发 | 每 10 ms 采样，稳定 30 ms，600 ms 后每 120 ms 连发 |
| [music.c](../firmware/Drivers/music.c) | 音调、旋律、滴答音、试听 | Timer0 输出和非阻塞音符推进 |
| [uart1.c](../firmware/Drivers/uart1.c) | 帧解析与回复 | ISR 接收、前台 Take 消费请求 |
| [settings.c](../firmware/Drivers/settings.c) | EEPROM 日志 | CRC、序列号、最后提交标记、断电恢复 |

## 定时器分工

Timer1：1T 模式、16 位自动重装载，`65536 - FOSC/1000`。11.0592 MHz 下计数 11059，周期约 0.999982 ms。每次中断刷新一位、累计时钟、推进音乐节拍和响铃时长；10 次中断产生前台节拍、1000 次产生秒事件。整数重装载误差约 1.56 秒/日，振荡源与 IAP 操作等还会带来额外误差，因此课程要求 `<5 秒/24 小时` 需要连续实测，不能仅靠计算认定达标。

Timer0：通过 P3.5/T0CLKO 输出方波。音调重装载为 `65536 - FOSC/(2*f)`，硬件每次溢出翻转引脚，两个溢出组成一个完整周期。前台不需要逐次翻转蜂鸣器。Timer1 只推进音符时长与间隔，闹钟优先于短滴答音。

Timer2：UART1 波特率发生器，重装载为 `65536 - FOSC/(4*115200)`，本配置计数 24，理想波特率为 115200。

## 显示与按键状态机

`app.c` 维护主显示状态和正在编辑的字段；P1.3 切换状态或确认字段，P1.4/P1.5 减加。时间与温度自动切换、学号滚动、字段闪烁和自动息屏都由节拍计数推进。

自动息屏只关闭数码管与冒号；MCU、计时、中断和串口继续运行。唤醒按键只负责亮屏，必须松开再按才执行原操作。立即息屏命令复用 `App_SleepScreen()`，不保存自动息屏开关。

## UART 中断与前台的边界

接收 ISR 按命令规定的字段数量收集数据，校验尾字节、BCD 与范围后把请求写入暂存区并置标志。`App_Service()` 用 `Uart1_Take*()` 消费请求、更新时间或 UI，并申请保存。

`06` ACK 表示接收解析器已接受写入帧，**不是 EEPROM 已持久化的确认**。温度回复在前台读取 ADC 后发送；发送时关闭 UART 中断 ES，Timer1 保持运行，每字节有等待上限。协议没有 CRC、帧间超时和请求队列，主机应一问一答；详情见[协议说明](protocol.md)。

## EEPROM 日志与断电语义

内部 IAP 地址 `0000H` 和 `0200H` 为两个 512 字节扇区，每条记录 20 字节，每扇区 25 条。记录包含格式版本、序列号、时间快照、三组闹钟、开关信息、CRC-8 和提交标记。先写数据与 CRC，最后写 `A5` 有效标记；恢复时只接受完整且合法的记录，扇区填满后换区。IAP 单步操作会暂时关闭中断，不应把它当成零开销存储。

保存发生在编辑全部确认或接受需要保存的串口修改后；正常走秒不保存。没有电池 RTC，也没有掉电中断记录最后一秒，重新上电恢复的是**最近一次成功保存的时间快照**。贪睡、滴答音开关、当前显示页和学号显示方式不持久化。旧有效记录缺少的闹钟/息屏开关按兼容规则默认为启用。

## 后续修改入口

更换时钟时修改 `FOSC`，同时检查 Keil 调试时钟、UART、音调和 IAP 等待参数；不能只改下载器频率。改变闹钟数量也不能只改 `ALARM_COUNT`：`board.h` 的数组长度、默认初始化、EEPROM 格式、解析器和上位机均按三组设计。添加外部 RTC 或精确 NTC 换算时，从 Board 层替换底层实现，再检查 UI 和协议表示范围。
