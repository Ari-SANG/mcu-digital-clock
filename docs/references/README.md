## STC15 数据手册：无需从头读 1473 页

[STC15 全系列中文资料 · 2015-06](【数据手册】STC15全系列中文资料2015-06(可复制版).pdf)，1473 页，约 28.1 MB。GitHub 可能无法直接预览整本，下载后用 PDF 阅读器检索。以下入口已核对 PDF 页序与对应章节；本文件在这些位置的印刷页号与 PDF 页序一致。

| PDF 页 / 章节 | 为什么看 |
| --- | --- |
| 292，第 2 章 | 时钟源、复位和省电模式；确认下载时钟配置 |
| 373，第 3 章；399，STC15W4K 新增 SFR 表 | `data`、`xdata` 存储空间与寄存器 |
| 400，第 4 章 | 准双向、推挽、高阻与开漏 GPIO；解释 P4.5 供电、按键与 ADC |
| 538，第 6 章 | 中断源、优先级与寄存器组 |
| 590，第 7 章；600～601，模式 0 自动重装载 | Timer1 的 1 ms 扫描和走时 |
| 645，Timer2；660，Timer2 作波特率发生器 | UART 的 Timer2 资源分工 |
| 714，第 8 章；738，Timer2 作 UART1 波特率发生器示例 | UART1 配置与接收中断 |
| 841，第 9 章；845，STC15W4K EEPROM 地址表 | IAP 读写、512 字节擦除与不同芯片容量 |
| 876，第 10 章 | ADC 控制、通道和 10 位结果拼接 |
| 1224，第 16 章；1277，ISP 原理与典型线路 | C51、头文件、下载工具和烧录恢复 |

同一本手册覆盖多种 STC15 型号。使用某个 SFR、EEPROM 地址或引脚复用前，确认它属于实际的 STC15W4KxxS4，不能套用其他系列。
