# 按键与功能操作

[阅读导航](README.md) · [串口助手说明](../tools/serial-assistant/README.md)

首次启动且无有效 EEPROM 记录时，时间为 12:00:00；三组闹钟分别为 08:00、12:00、16:00，均启用；音乐依次为《欢乐颂》《天空之城》《曹操》。自动息屏和滴答音默认启用。

## 正常显示

| 操作 | 效果 |
| --- | --- |
| P1.3 | 时钟/温度 → 学号 → 闹钟 → 时钟/温度 |
| 时钟页 P1.4 | 进入时钟编辑 |
| 闹钟页 P1.4 | 编辑当前选中闹钟 |
| 时钟页 P1.5 | 开关每秒滴答音 |
| 学号页 P1.5 | 滚动完整学号 / 固定末四位 |
| 闹钟页 P1.5 | 切换闹钟 1、2、3 |

四位数码管每 3 秒在 HH:MM 与 MM:SS 间交替。在时钟状态空闲 10 秒后显示温度，再过 10 秒显示时间；按键返回时间页。温度 `261C` 配合第二位后的小数点表示 26.1°C。

学号在 `firmware/config.h` 的 `STUDENT_ID_TEXT` 设置；启动默认滚动，固定显示取最后四位。

## 编辑

P1.4 减小闪烁字段，P1.5 增大；长按 600 ms 后每 120 ms 连发。P1.3 确认并移动字段：时钟依次为时 → 分 → 秒 → 完成；闹钟依次为时 → 分 → 音乐 → 完成。全部确认后申请写 EEPROM。

音乐字段 `A1-2` 表示第 1 组闹钟使用第 2 首音乐。加减切换音乐并重新开始约 6 秒试听，确认停止试听并完成编辑。

## 响铃与息屏

响铃最长 30 秒，循环所选旋律。P1.3 停止并从按下时刻起贪睡 10 分钟；P1.4/P1.5 停止且不贪睡。贪睡不改变每日闹钟时间，不写 EEPROM。

启用自动息屏后连续 60 秒无按键关闭数码管和冒号，计时、闹钟、音乐与 UART 保持运行。首次按键唤醒，松开再按才执行功能；响铃唤醒。串口校时、设置闹钟时间/音乐、修改自动息屏开关也会唤醒；单独修改闹钟开关不应当作唤醒命令。

电脑助手的“息屏设置”页可开关自动息屏，也可发一次“立即息屏”；立即息屏不保存任何设置。

## 上位机使用

打开 C# 串口助手，选 CH340 COM 口并连接；“时间同步”校准电脑时间或手动发送，“闹钟设置”分别写时间/音乐和启用开关，“温度显示”查询或自动刷新，“息屏设置”控制显示。

助手保持连接，禁用 DTR/RTS，打开后等待 1.5 秒。勾选框代表待写值，**不是 MCU 当前设置读回**。该协议没有闹钟/开关状态读取命令。写操作收到 ACK 才显示成功；温度自动刷新只在温度页活动，失败会停止。

## 人工验收路线

1. 烧录后确认时间、冒号、四位扫描正常，操作按键没有明显重影或卡顿。
2. 修改并完整确认时间；分别检查三组闹钟、音乐试听与贪睡。
3. 校时发送 `01 19 35 50 AA`，确认 ACK 和显示变化；查询 `05 AA`。
4. 自动息屏开关、立即息屏、按键唤醒及闹钟唤醒逐项检查。
5. 设置后等待 EEPROM 保存完成再断电，核对恢复的是保存快照。
6. 与可靠参考钟连续对比 24 小时；温度在多个室温点与参考温度计对比。
